01

Mark & wordmark

Ground Control

Clear space equals the mark's inner-circle diameter on all four sides. Nothing enters it.

Three cut sizes. Below 20px the dashed orbit is dropped — never scaled. 16px is the tray floor.

✕Never set the wordmark in the UI face, and never set UI copy in Archivo.
✕Never recolor the satellite dot to a status hue.
✕Never stack, rotate, or tighten below .145em tracking.

Archivo 600 is brand-only. Everything inside the product is system sans.

02

Four sets, none of which overlap: neutrals build the surface, status is reserved for state, project chips are categorical identity, and one accent marks the product's own voice. Dark values are chosen against the dark surface, not derived from the light ones.

Rules

  • One family in product: system-ui. Six sizes: 11 · 12 · 13 · 15 · 20 · 40.
  • tabular-nums on everything that stacks in a column. Stat figures are the one exception — proportional, so 14 doesn't sit in a puddle of space.
  • Weight carries hierarchy before size does. 400 → 500 → 600, nothing heavier.
  • Text is never a status color. A shape token beside it carries the state.
  • Row titles truncate with an ellipsis at one line; identifiers never truncate.
04

Status language

Every state is a triple: shape, color, label. Each severity gets its own silhouette, so the four levels stay distinguishable in greyscale, at 11px, and for the ~8% of male developers with a red-green deficiency.

{{ t.label }} {{ t.use }} {{ t.shape }}

Iconography

  • 14px box, 1.25px stroke, geometric primitives only — circle, square, triangle, diamond, line. No pictograms, no emoji.
  • Status tokens are filled solids. Correlation badges are outlined. Fill means state; outline means fact.
  • Badges show glyph only at rest and expand to glyph + label on row hover.
  • An absent badge is information: "assigned to me, nothing started" is a row with three empty slots, drawn as hairline placeholders rather than omitted.

05

Row anatomy

One 34px primitive serves all three lanes. Slots are fixed-width and always present, so the columns align down the lane and an empty slot reads as an absence rather than a shift.

06

Motion

The one loop

A 2.4s opacity+scale pulse on the accent dot. Permitted on exactly two referents: an agent session that is actually streaming, and a CI run in progress. It stops the moment the thing stops.

State change

200ms, cubic-bezier(.2,.7,.3,1). A row that changed status settles into its new sort position; a stat figure counts to its new value. Nothing animates on first paint.

Hover

120ms. Row lifts to the raised surface, correlation badges expand from glyph to glyph+label, row actions fade in at the trailing edge. No transform, no shadow — density is preserved.
